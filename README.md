#  HelpDesk Telegram Bot (ТОВ «Активольт»)

Цей проєкт — це Telegram-бот для автоматизації роботи відділу технічної підтримки. Розроблений під час проходження виробничої практики.

##  Структура проєкту
- `bot.py` — головний файл програми (інтерфейс бота, FSM, взаємодія з API).
- `database.py` — модуль для роботи з базою даних SQLite (CRUD операції).
- `.env` — файл для безпечного зберігання секретного токена бота.
- `requirements.txt` — перелік залежностей для розгортання на сервері.
- `helpdesk.db` — локальний файл бази даних (генерується автоматично).

##  Використані технології
- **Мова:** Python 3.10+
- **Фреймворк:** aiogram 3.x (асинхронна робота)
- **База даних:** SQLite3
- **Зовнішнє API:** REST API (qrserver.com) для генерації QR-кодів
- **Робота з файлами:** вбудована бібліотека `csv` для експорту звітів.

##  Інструкція щодо встановлення та запуску
1. Встановіть Python та завантажте файли проєкту.
2. Встановіть необхідні бібліотеки командою: `pip install -r requirements.txt`
3. Створіть файл `.env` та додайте свій токен: `BOT_TOKEN=ваш_токен`
4. Запустіть файл ініціалізації БД: `python database.py`
5. Запустіть бота: `python bot.py`
